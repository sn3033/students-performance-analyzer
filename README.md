# Student Performance Analyzer

A Python CLI application to analyze student marks,
calculate grades, and generate performance reports.

## Features
- Accepts marks for five subjects
- Validates marks between 0 and 100
- Calculates total and percentage
- Assigns grades automatically
- Displays the student's result

## Technologies
- Python 3

## Concepts Used
- Functions
- Dictionaries
- Loops and conditionals
- Input validation
- Arithmetic operations

## How to Run
Run the program using:

    python main.py
